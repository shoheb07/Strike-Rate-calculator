# Strike-Rate-calculator
The Strike Rate Calculator is a simple web-based application developed using HTML, CSS, and JavaScript. The project is designed to calculate the strike rate of a cricket batter based on the number of runs scored and balls faced.

# Strike Rate Calculator

## Project Overview

The Strike Rate Calculator is a web application developed using HTML, CSS, and JavaScript. It calculates the strike rate of a cricket batter based on runs scored and balls faced.

The application provides instant calculation results with a simple and responsive user interface.


# Features

- Calculate cricket strike rate
- User-friendly interface
- Input validation
- Instant result display
- Responsive design


# Technologies Used

- HTML5
- CSS3
- JavaScript

# Formula Used

Strike Rate = (Runs / Balls) × 100


# Example

Runs Scored = 80
Balls Faced = 50

Strike Rate = 160
